# Represent closed-set Gaussian semantics with Dirichlet posteriors

Each Gaussian uses an eight-class categorical–Dirichlet state with a symmetric prior of total concentration one. This preserves fractional visibility-weighted evidence, separates observation scarcity from class conflict, and supports probabilistic TDOM rasterization without iterative semantic training; arbitrary learned feature embeddings are not the V1 authority.
