# 最小地图产品与在线语义收尾，2026-10-21

生产代码提交 `d134eae`，独立分支 `perf/semantic-minimal-online-final-20261021`。主 checkout 和原始数据未修改。

## 最终默认行为

- 渐进训练持续维护高斯语义，默认在最终阶段直接复用；先排空异步工作、处理已接受的新观测、关闭当前证据组，再按最终几何保存状态和发布地图。
- 默认不执行两遍全量语义重投影，不用重新累计的状态替换在线状态。最终状态为 `approx_final`，保留真实的 `historical_evidence_stale` 标记。相机/标签绑定、零 lag、无错误及无延迟观测的要求仍然存在。
- `--semantic_final_rebuild` 显式启用原有全量重建；完整输入时发布 `exact_final`。该开关关闭且只请求最终地图时，在线语义仍持续更新。开启该开关、没有过程视频/语义检查点时，可按原流程把语义计算推迟到最后。
- 默认地图栅格只有 `rgb/tdom.png` 和 `semantic/semantic_color.png`。保留小型对齐、类别、调色板及校验清单；模型/语义状态归档是独立接口，并非额外地图栅格。

辅助栅格分别通过以下参数开启：

| 参数 | 输出 |
|---|---|
| `--semantic_tdom_save_class_ids` | 整数类别 ID |
| `--semantic_tdom_save_masks` | 未知区域/原因，以及可用的平面补洞来源 |
| `--semantic_tdom_save_evidence` | 证据支持度 TIFF |
| `--semantic_tdom_save_entropy` | 语义熵 TIFF |
| `--semantic_tdom_save_diagnostics` | 全部旧式辅助栅格 |
| `--semantic_tdom_save_probabilities` | 概率数组 |

地图 manifest 升为 schema 4，记录实际启用的 `export_options` 和文件哈希。输出预算和降级策略按所选栅格估算。平面补洞依赖最终精确分组，显式启用时需要 `--semantic_final_rebuild`；已有验证工具也会提示需要哪些可选栅格。

## 固定最终地图回放

输入为已经保存的 phantom3 最终像素网格，10240×12800（1.31亿像素）。RGB、类别ID、未知原因及解码后的量化辅助栅格相同，调色板从原始发布清单恢复。分别调用修改前 `588a037` 和新默认配置的公开配对发布器；输入解码、加载及事后校验不计入发布耗时。CPU线程预算4，不使用CUDA。

| 实测项目 | 原默认 | 新默认 |
|---|---:|---:|
| 语义产品写出与哈希 | 22.178 秒 | 11.405 秒 |
| RGB＋语义配对发布 | 56.174 秒 | 42.985 秒 |
| 发布文件总字节 | 466,182,138 | 75,538,666 |

这一次回放中，语义导出耗时下降48.58%，配对发布下降23.48%，体积下降83.80%。两张必要PNG的SHA256均与原始发布结果一致；导出精简没有改变这些固定像素的结果。

不能把本次回放直接与历史整场的144.66秒相减：本次从保存的量化栅格恢复输入，运行日期、进程上下文、系统负载和缓存也不同。这里没有据此宣称整场训练加速比例。首次回放遗漏调色板覆盖配置，被PNG哈希断言拦截；该无效样本已排除并保留说明，最终两次结果均恢复了相同调色板。

## 真实训练与校验

物理GPU0上顺序运行两条原始phantom3烟测：stage14–18，18个累计相机，每条6800次优化（初始化2000、四阶段各100局部＋100全局、最终4000），原生1870×1049，地图GSD0.02。它们用于功能验收，不是两种模式的性能或质量优劣实验。

- 默认在线模式：没有过程视频，在线语义持续更新；`approx_final`、lag0、18条唯一观测、无错误/延迟，保存状态可通过公开loader重载；仅两张地图栅格，没有全量重建指标文件。
- 显式重建模式：`exact_final`，18张标签进入重建；额外开启类别ID输出和六帧视频，地图哈希与视频完整解码通过。
- 两条路径的几何、语义状态、类别schema和输入绑定均校验通过。最终语义metadata独立于重建指标归档，在线模式还会移除上次中断尝试遗留的重建指标，避免误报。
- 269项测试在物理GPU0通过，包含CUDA、拓扑/异步捕获、在线最终状态保留、缺失输入拒绝、精确重建保留、辅助输出选择及发布事务校验。
- 6084个原始数据文件哈希与此前完整实验一致。所有训练/回放子进程对原始数据、已有实验、代码及共享Conda使用只读挂载，仅本次新实验目录可写；未使用物理GPU1，未修改CUDA扩展。

本次没有重跑新默认配置的414相机完整训练，也没有新增人工语义真值评估。导出回放中的PNG等价只针对固定像素输入；改用在线最终状态可能得到不同于全量重建的语义结果。此前完整phantom3记录中的在线/重建高斯类别一致率86.23%属于两个状态之间的对照，不是准确率，也不能据此证明哪种模式更好。

实验根目录：`/data3/xzp/experiments/Onthefly/phantom3/semantic-minimal-export-20261021`。其中 `summary.json` 为完整结构化结果，`validation/final-verification.json` 为产物与原始数据校验，`validation/all-tests-gpu0.log` 为测试日志。代码与执行约定见 ADR0012。
