# 语义流水线优化与完整对照，2026-10-21

代码提交 `7a92357186be554a2c58ea6774a720c0e8c25b89`，分支 `perf/semantic-pipeline-20261021`，独立 worktree。直接基线为上一轮已验收的 `semantic-performance-20261021/full-original-1612`（代码 `d6df0c1`），即每新增影像 4.543 秒的版本。本轮保留其几何采样、优化器、精确边界权重定义、原始输入与训练参数。

完整原始 XinCao 运行成功完成：229 张累计相机、stage 30–229、45800 次优化、最终 `exact_final`、120 帧 H.264 视频。增量端到端均值 **4.543 → 3.612 秒/新增影像**，实测耗时下降 20.49%。最终语义重建 **173.096 → 80.949 秒**。

## 实现与边界

1. 只复用与高斯几何无关的整流标签、训练网格类别 ID 和边界权重。缓存键绑定原始数组内容/dtype/shape、原始标定、相机掩膜、目标尺寸、ignore ID、带宽/floor、像素坐标约定和版本。128 MiB CPU LRU、512 MiB 压缩派生文件上限，另有一份原子写入临时文件；目录只位于新实验输出。磁盘内容校验失败会重新计算。标签加载、元数据/分数校验、最终前后输入绑定均未省略，两遍最终高斯投影仍执行，类别 ID 保持最近邻。
2. 初始化和增量视频捕获与该阶段的语义更新一起排入同一个有序 worker。完整 RGB 模型、相机、背景、地图范围、轨迹和 stage/iteration 在提交时冻结；worker 在消费后续拓扑事件之前渲染该阶段两幅地图。不复制整份语义状态，不读取实时训练模型。最多保留两个视频任务（含正在执行任务），满额时产生明确的前台背压。最终精调先排空旧任务，再精确重建并同步生成最后一帧。

更早准备好输入会影响既有“训练过半后可响应 Render_New”策略下实际使用的预览时刻，因此不承诺模型轨迹逐位一致；必须看完整质量检查。

数学和产品状态合同不变，执行约定见 [ADR 0011](/home/xuzipeng/code/Semantic-A-TDOM/worktrees/semantic-pipeline-20261021/docs/decisions/0011-ordered-progress-capture-and-label-reuse.md)。本轮没有再次修改透视采样，也没有修改共享环境或 CUDA 扩展。

第一版异步方案在 GPU 4 完整运行后，平均每帧为 5.034 秒，高于 4.543 秒基线，未通过性能验收，记录完整保留。本版进一步跳过训练器不会消费的旧相机全分辨率掩膜计算/整流和相应 IPC 负载，条件与训练器已有的 FOV/标定替换判据完全一致；新相机或标定变化仍重建影像和掩膜。完整运行中跳过了 7745 次旧相机掩膜准备。真实 stage-180 的 27 旧相机回放为 3.413 → 0.002 秒，位姿和标定字段一致。本版初始化视频任务在打开增量流之前完成，避免把启动积压计到某个增量帧；完整墙钟仍包含这项成本。

所有增量均值的分母为 199 个新增影像阶段，包括无需视频采样的阶段。前台语义提交包含快照创建和容量背压，不能再把背压额外相加一次。初始化语义任务的一部分可以延后到增量阶段，因此应同时检查整场墙钟，不能只按增量均值推算总收益。监督程序耗时为 19.187 分钟，还包含训练结束后的受保护文件哈希核验，与训练 manifest 墙钟分别记录。

基线完整训练使用物理 GPU 2，本轮改用物理 GPU 4，两者均为 RTX 4090，原始输入和参数相同。原 GPU 2 重跑中出现外部计算进程，计时受到污染，已只中止本任务的进程并保留记录，未操作外部进程。本轮从启动起检查和采样 GPU 4 的计算进程，要求无外部计算任务。不同物理设备以及共享资源仍限制性能归因。CPU/存储是共享资源，运行日期/时段不同；这些是单次完整运行实测值，不是跨场景的固定收益。本次完整训练期间没有并行模型评估、微基准或调试器暂停；GPU 进程采样结果另行留档。

视频任务提交 119 次、完成 119 次、结束待处理 0 次，最大同时保留 1 次。累计前台容量背压为 **0.001 秒**。类别准备共 926 次调用，内存命中 239 次、磁盘命中 458 次、重算 229 次，累计准备时间 176.231 秒；无损坏缓存或写入错误。结束时 CPU 缓存 120.81 MiB、磁盘缓存 38.37 MiB。

阶段 CUDA 峰值沿用原来的进程级采样计数；后台分配与前台重置可能交错，不等同于整机显存峰值。原始逐阶段记录及统计见 [summary.json](/data3/xzp/experiments/Onthefly/XinCao/semantic-pipeline-final-20261021/comparison/summary.json)。

## 质量与产品验证

RGB 对相同 229 个训练视图、原始 RGB、1612×1209 网格、标定和掩膜进行评估；相机/掩膜哈希与基线相同。基线值来自上一轮已归档的 GPU 4 评估，复制来源和 SHA256 单独记录。本轮保存模型也在物理 GPU 4 使用相同实现评估。

本次均值略有改善：PSNR +0.04020 dB、SSIM +0.001445、LPIPS-VGG −0.001770，191/229 个视图的 PSNR 提高。固定视图与地图总览已人工查看，主要结构一致，差异主要位于纹理细节、类别边缘及地图外围。最终高斯数量为 1,026,016，参考为 1,009,842；预算和训练次数相同，但实际自适应采样轨迹与数量不同，因此不能把质量变化单独归因于缓存。

这是训练视图重建质量，不是留出视图泛化测试。独立训练存在 GPU 浮点累计与优化轨迹差异；缓存输出逐位一致不等于最终模型逐位一致。逐帧差值、极值与分位数保留在结构化结果和 CSV 中，不能仅凭均值宣称所有视图改善。

## 验收证据与剩余问题

- 全集 **288 个测试及 68 个子测试通过**，包括已安装 CUDA 集成、跨拓扑事件的冻结捕获、容量背压、异常传递及缓存失效/损坏/配额。
- 旧实际捕获函数在新回归检查中触发前台等待而失败，新路径通过；重复准备检查从两次边界计算变为一次准备、两次高斯光栅化。
- 229 张原始影像的训练网格 ID/权重与已归档无缓存参考哈希全部一致，首次计算及磁盘重载均通过。
- 34 相机、2560 次优化烟测通过最终语义、地图哈希和六帧完整解码。另三份 80 次迭代烟测（包含优化前原版）在最终地图发布遇到 CUDA 非法访问，已保留为预先存在的短训练/渲染问题，本轮未改扩展来处理它。
- 完整实验的 120 个视频边界，其 stage、phase、iteration、已接受相机数量和 semantic-through 身份与基线逐项一致；全部 lag 为零。初始 stage 30 接受 30 个相机，但最大身份为 000031，两个既有基线也是如此，stage 号不等于最大影像 ID。
- 最终 schema-5 状态通过公开 loader 重载；229 张影像、183 个语义组、无错误或 deferred，全部地图产品哈希和 H.264 全片解码通过。
- 原始 RGB/SfM/标签、旧实验及主 checkout 的 3406 个受保护文件哈希前后相同。物理 GPU 1 未参与。
- 已有地图列方向元数据与实际投影相反的问题仍未混入本轮修复；对齐使用实际投影矩阵。历史修复后整场为何突然变慢的唯一触发原因也未被本轮宣称已查明。
