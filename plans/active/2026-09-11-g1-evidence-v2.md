# G1 Evidence V2 Implementation Plan

**Status:** Active.

**Goal:** Replace the internally inconsistent prior-weighted semantic renderer with an evidence-conditioned G1 contract, then implement and validate that contract without allowing semantics to affect A-TDOM geometry.

**Architecture:** Keep semantic state as a non-optimizable sidecar. Separate observed class evidence from the symmetric Dirichlet prior, treat online products as bounded approximations, and rebuild authoritative semantics from all valid labels on frozen final geometry. Establish the CPU reference and schemas before changing CUDA.

**Current branch:** `semantic/g1-evidence-v2`

## Global constraints

- Do not read from or copy code from A-TDOM_Online.
- Do not modify `ref/A-TDOM`.
- Preserve the geometry firewall: semantic state, losses, failures and scheduling must never alter RGB optimization or Gaussian topology decisions.
- Treat `/data3/xzp/data/Onthefly/phantom3` and `/data3/xzp/data/Onthefly/semantic_labels` as read-only inputs.
- Preserve unrelated worktree changes.
- Use a new semantic method/schema version; never silently resume an older sidecar under changed mathematics.
- Stabilize and test the CPU mathematical contract before changing CUDA.
